03 GPU Auto-Detection Logic
Detection Script: 06-distro-gpu-params
Runs lspci during grub2-mkconfig and checks for GPU vendor strings. Supports hybrid laptops (dual GPU) by applying both discrete and integrated params.

Detection priority:
1. NVIDIA (RTX/GTX/Quadro) → injects nvidia-drm.modeset=1, blacklist nouveau, pre-load nvidia modules
2. AMD (Radeon/RDNA) → injects amdgpu.ppfeaturemask, pre-load amdgpu
3. Intel (UHD/Iris/Arc) → injects i915.enable_guc=3, fastboot
4. Hybrid → applies both discrete + integrated params
Always-Applied Params
Regardless of GPU, these gaming/performance parameters are always added:

split_lock_detect=off — fixes emulator/Wine performance
preempt=full — low-latency scheduling
transparent_hugepage=madvise — avoids latency spikes
mitigations=off — disables CPU mitigations (configurable)
loglevel=3 — clean boot (Plymouth handles visuals)
systemd.show_status=0 — hide systemd messages
04 Bootloader Comparison
GRUB2 (Default)
Fedora's default bootloader. Mature, feature-rich, supports both UEFI and BIOS.

UEFI + BIOS Btrfs snapshots Theme support OS Prober Scriptable

Pros: Works everywhere, snapshot booting via snapper plugin, large community support
Cons: More complex config, slightly slower boot than systemd-boot
systemd-boot (Alternative)
Simpler, faster UEFI-only bootloader. Individual .conf entries per kernel.

UEFI only Simple .conf entries Fast boot kernel-install hooks

Pros: Faster, simpler config, native kernel-install integration
Cons: UEFI only, no btrfs snapshot menu (manual rollback), less themeable
05 Safety & Recovery
Fallback Boot Entry
Both GRUB and systemd-boot include a fallback entry that boots with nomodeset and all GPU drivers blacklisted. Guarantees a working TTY even if drivers are completely broken.
Btrfs Snapshot Rollback
If snapper or timeshift is active, snapshot boot entries appear in the GRUB menu. Boot into any pre-update snapshot to roll back a broken system in seconds.
Dracut Hostonly
Initramfs uses hostonly=yes — only includes modules for the current hardware. Smaller initramfs, faster boot. A full fallback initramfs is also generated for the safe-mode entry.
