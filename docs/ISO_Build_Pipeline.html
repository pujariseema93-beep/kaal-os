03 Post-Install Script Chain
01 — GPU Detection
Runs lspci, detects NVIDIA/AMD/Intel, installs correct driver, configures kernel parameters, regenerates GRUB + initramfs.
NVIDIA AMD Intel
02 — DE Installation
Installs the selected desktop environment via DNF. Creates default configs for Hyprland/Sway. Enables the correct display manager (SDDM/GDM/LightDM).
KDE GNOME Hyprland Sway XFCE Cinnamon
03 — Profile Installation
Reads the selected profile package list from /usr/share/distro/profiles/ and installs all packages via DNF5. Runs profile-specific post-setup.
gaming.list developer.list daily.list
04 — Bootloader Setup
Calls distro-bootloader-setup --install to install GRUB2 or systemd-boot to the ESP. Detects GPU and generates correct kernel command line.
05 — Auto-Update Setup
Creates the kaal-update-check.service systemd service and timer. Configures update preferences (mode, interval, metered, snapshot).
06 — System Tuning
CPU governor, I/O scheduler (BFQ for SATA, none for NVMe), zram config, sysctl tuning for gaming (inotify watches, swappiness, max_map_count), limits.conf.
07 — Finalize
Removes live user, creates install record, cleans DNF cache, final GRUB + initramfs regeneration, enables first-boot service.
First Boot Service
Runs once on first boot after installation. Detects GPU, builds NVIDIA akmod, regenerates initramfs, enables display manager, configures zram + snapper.

05 Two Build Methods
Method 1: livemedia-creator (Default)
Fedora's standard ISO builder, part of the Lorax toolset. Consumes the kickstart file directly.

Fedora-standard Kickstart-driven Reproducible

sudo ./build-iso.sh --releasever 42

Pros: Official Fedora tool, well-documented, uses kickstart syntax
Cons: Slower, less flexible output formats
Method 2: kiwi-NG (Alternative)
Modern image builder from SUSE. XML-based config, supports ISO/disk/containers.

Multiple formats XML config Modern

sudo ./build-iso-kiwi.sh

Pros: Can produce ISO, qcow2, raw, OCI container from same config
Cons: Less Fedora-specific documentation
Build requirements: A Fedora 40+ host (bare metal or VM) with root access, ~20GB disk space, and the lorax / xorriso packages. Build takes 30-60 minutes depending on network speed and hardware. The resulting ISO is a hybrid UEFI+BIOS live image with Calamares installer.
